# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-02-17

### Added
- Initial release
- FastAPI application for job management
- RQ worker integration for asynchronous job processing
- Redis queue backend
- Example worker tasks (transform_data, process_csv)
- Docker and docker-compose setup
- RQ Dashboard for monitoring
- Authentication system (API keys + OAuth)
- Comprehensive test suite
